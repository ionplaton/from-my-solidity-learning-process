# Белот онлайн: Telegram Mini App и веб‑версия

Белот на 2, 3 или 4 игроков через интернет: каждый на своём телефоне, где бы он ни был.
Работает как **мини‑приложение в Telegram** и как обычная **страница в браузере** (ссылку можно отправить и в WhatsApp).
Android и iPhone — без установки.

- `src/engine.js`, `src/bot.js` — правила, подсчёт очков и боты (точная копия движка Android‑приложения;
  тест `test/crosscheck.test.js` проверяет это на партиях, записанных из Kotlin‑версии).
- `src/rooms.js` — столы: коды, места, команды, боты, переподключение.
- `src/server.js` — веб‑сервер (раздаёт страницу) + WebSocket (`/ws`) для игры.
- `public/` — интерфейс (без сборки, обычный JavaScript).

Проверка: `npm install && npm test`. Запуск у себя: `npm start` → http://localhost:8080

## Как запустить бесплатно (один раз, ~10 минут)

Нужны две вещи: сервер в интернете (бесплатно на Render) и бот в Telegram (через @BotFather).

### 1. Сервер на Render

1. Откройте https://render.com и войдите через GitHub (**Sign in with GitHub**).
2. **New → Web Service** → выберите репозиторий `from-my-solidity-learning-process`.
3. Заполните:
   - **Branch**: ветка с игрой (`ccr-56ab3187-kefqyx`, или `main`, если её туда слили);
   - **Root Directory**: `belot-web`;
   - **Runtime**: Node;
   - **Build Command**: `npm install`;
   - **Start Command**: `npm start`;
   - **Region**: Frankfurt (ближе всего к Молдове);
   - **Instance Type**: **Free**.
4. **Create Web Service**. Через пару минут появится адрес вида `https://belot-xxxx.onrender.com`.
   Откройте его — должна загрузиться игра. Уже сейчас можно играть просто по ссылке в браузере.

Бесплатный сервер «засыпает», если им 15 минут никто не пользуется. Первое открытие после этого
занимает до минуты — игра покажет «Подключаемся…» и подождёт. Во время игры сервер не засыпает.

### 2. Бот и мини‑приложение в Telegram

1. В Telegram откройте **@BotFather** → `/newbot` → придумайте название (например «Белот») и имя бота,
   оканчивающееся на `bot` (например `belot_nashi_bot`).
2. В @BotFather: `/mybots` → ваш бот → **Bot Settings** → **Configure Mini App** → **Enable Mini App** →
   отправьте адрес с Render (`https://belot-xxxx.onrender.com`).
3. (Желательно) там же **Bot Settings → Menu Button** → тот же адрес, название кнопки «Играть».
4. На Render: ваш сервис → **Environment** → **Add Environment Variable**:
   `BOT_USERNAME` = имя бота без `@` (например `belot_nashi_bot`) → **Save**. Сервис перезапустится.
   Теперь кнопка «Пригласить» в игре будет давать ссылки, которые открывают стол прямо в Telegram.

Токен бота никуда вводить не нужно.

## Как играть

1. Откройте бота в Telegram и нажмите **«Играть»** (или **Open**).
2. **Создать стол** → выберите, сколько игроков (2, 3 или 4) → **Пригласить в Telegram** → выберите вашу группу.
3. Друзья нажимают на ссылку в группе — мини‑приложение откроется сразу за вашим столом.
4. Когда все сели (на пустые места можно посадить ботов) — **Начать игру**.

Вчетвером играют двое на двое: места 1 и 3 против 2 и 4, создатель стола может пересадить игроков кнопкой «↓».
Если у кого‑то пропала связь, он просто снова открывает ссылку на стол — место сохраняется.
Ссылку на стол можно отправить и в WhatsApp: там она откроется в браузере.

Столы хранятся в памяти сервера: если сервер перезапустился (или заснул), нужно создать новый стол.
