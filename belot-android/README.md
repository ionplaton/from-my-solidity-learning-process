# Белот на троих (Android)

Приложение для игры в белот втроём, каждый на своём телефоне. Телефоны соединяются по Wi‑Fi:
либо все подключены к одному роутеру, либо двое подключаются к точке доступа третьего телефона.
Интернет не нужен.

## Как установить

1. Откройте страницу [Releases](https://github.com/ionplaton/from-my-solidity-learning-process/releases)
   и скачайте последний файл `belot-….apk` (его собирает GitHub Actions при каждом изменении).
2. Отправьте этот файл друзьям (Telegram, WhatsApp, Bluetooth — как удобно).
3. На каждом телефоне откройте файл и разрешите установку из этого источника.

Новые сборки подписаны тем же ключом, поэтому устанавливаются поверх старой версии.

## Как играть

1. Все телефоны — в одной Wi‑Fi сети (или подключены к точке доступа одного из телефонов).
2. Один игрок нажимает **«Создать стол»**. На экране появится адрес стола (например `192.168.1.5`).
3. Двое других нажимают **«Присоединиться к столу»** — стол найдётся сам. Если не находится,
   введите адрес вручную.
4. Создатель стола выбирает правила и нажимает **«Начать игру»**. Если игроков двое, на пустое место
   можно посадить бота. Есть и режим **«Играть с ботами»** для одного человека.

Если телефон потерял связь, игра ждёт. Игрок может вернуться: «Присоединиться» с тем же именем.
Создатель стола может заменить отключившегося игрока ботом.

## Правила (вариант на троих)

- 24 карты: 9, 10, В, Д, К, Т. Каждый играет сам за себя.
- Сдаётся по 5 карт, следующая открывается. Круг 1: взять масть открытой карты козырем или пас.
  Круг 2: назвать другую масть или пас. Если все спасовали — пересдача.
- Взявший получает открытую карту и ещё 2, остальные — по 3 (у всех по 8).
- Ходить в масть; нет масти — козырем; на козырь нужно отвечать старшим козырем, если он есть.
- Козыри: В 20, 9 14, Т 11, 10 10, К 4, Д 3. Прочие масти: Т 11, 10 10, К 4, Д 3, В 2, 9 0.
  Последняя взятка +10, все 8 взяток +90.
- Комбинации: терц 20, пятьдесят 50, сто 100; каре В 200, каре 9 150, остальные каре 100;
  бела (К+Д козыря) 20. Последовательности засчитываются только у игрока с самой старшей из них,
  каре — только у игрока с самым старшим каре.
- Взявший козырь должен набрать больше каждого соперника (настраивается: «больше половины»).
  Иначе он получает только белу, а его остальные очки делятся поровну между соперниками.
- Игра до 301 / 501 / 1001 очка (выбирает создатель стола).

Правила белота сильно различаются по регионам. Если вы играете иначе, логику легко поменять:
она собрана в `core/src/main/kotlin/belot/core/BelotGame.kt`.

## Для разработчика

- `core/` — игровая логика, боты и сетевой протокол (чистый Kotlin, без Android). Тесты:
  `./gradlew -PcoreOnly :core:test` (Android SDK не нужен).
- `app/` — Android‑приложение (без AndroidX, весь интерфейс рисуется кодом).
- Сборка APK: `./gradlew :app:assembleRelease` (нужен Android SDK) или GitHub Actions
  (`.github/workflows/belot-android.yml`).
- Сеть: создатель стола запускает TCP‑сервер (порт 47321) и рассылает UDP‑маяк (порт 47322)
  для автопоиска. Все решения принимает сервер; каждому телефону приходят только его карты.
- Ключ подписи `app/belot-shared.jks` лежит в репозитории специально, чтобы любая сборка
  ставилась поверх предыдущей. Для публикации в магазине его нужно заменить на свой секретный ключ.
