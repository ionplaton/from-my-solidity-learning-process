# Белот (Android): вдвоём, втроём, вчетвером

> Хотите играть через интернет, из разных мест, или у кого‑то iPhone? Есть онлайн‑версия и мини‑приложение
> Telegram с теми же правилами: [`belot-web/`](../belot-web/README.md).

Приложение для игры в белот на 2, 3 или 4 игроков, каждый на своём телефоне. Телефоны соединяются по Wi‑Fi:
либо все подключены к одному роутеру, либо двое подключаются к точке доступа третьего телефона.
Интернет не нужен.

## Как установить

1. Откройте страницу [Releases](https://github.com/ionplaton/from-my-solidity-learning-process/releases)
   и скачайте последний файл `belot-….apk` (его собирает GitHub Actions при каждом изменении).
2. Отправьте этот файл друзьям (Telegram, WhatsApp, Bluetooth — как удобно).
3. На каждом телефоне откройте файл и разрешите установку из этого источника.

Новые сборки подписаны тем же ключом, поэтому устанавливаются поверх старой версии.

## Как играть

1. Все телефоны — в одной Wi‑Fi сети (или подключены к точке доступа одного из телефонов).
2. Один игрок нажимает **«Создать стол»** и выбирает, сколько игроков: двое, трое или четверо.
   На экране появится адрес стола (например `192.168.1.5`).
3. Остальные нажимают **«Присоединиться к столу»** — стол найдётся сам. Если не находится,
   введите адрес вручную.
4. Вчетвером играют двое на двое: места 1 и 3 против мест 2 и 4. Создатель стола может пересадить
   игроков кнопкой «↓», чтобы выбрать партнёров.
5. Создатель стола выбирает правила и нажимает **«Начать игру»**. На пустые места можно посадить ботов.
   Есть и тренировка с ботами (вдвоём, втроём, вчетвером) для одного человека.

Если телефон потерял связь, игра ждёт. Игрок может вернуться: «Присоединиться» с тем же именем.
Создатель стола может заменить отключившегося игрока ботом.

## Правила

| | Вдвоём | Втроём | Вчетвером |
|---|---|---|---|
| Кто против кого | один на один | каждый за себя | двое на двое (партнёр напротив) |
| Колода | 24 карты (9–Т) | 24 карты (9–Т) | 32 карты (7–Т) |
| Карт на руках | 12 | 8 | 8 |
| Первая сдача | по 6 | по 5 | по 5 |

- После первой сдачи открывается карта. Круг 1: взять её масть козырем или пас.
  Круг 2: назвать другую масть или пас. Если все спасовали — пересдача. Взявший получает открытую карту,
  затем всем досдаются карты до полной руки.
- Ходить в масть; нет масти — козырем; на козырь отвечать старшим козырем, если он есть.
  Вчетвером, если взятку берёт партнёр, а масти нет, можно класть любую карту.
- Козыри: В 20, 9 14, Т 11, 10 10, К 4, Д 3, 8 и 7 — 0. Прочие масти: Т 11, 10 10, К 4, Д 3, В 2, 9/8/7 — 0.
  Последняя взятка +10, все взятки +90.
- Комбинации: терц 20, пятьдесят 50, сто 100; каре В 200, каре 9 150, каре Т/10/К/Д 100 (каре 7 и 8 не считаются);
  бела (К+Д козыря) 20. Последовательности засчитываются только стороне (игроку или команде) с самой старшей из них,
  каре — только стороне с самым старшим каре.
- Вдвоём и вчетвером взявшие козырь должны набрать больше соперников, иначе все очки (кроме белы) уходят соперникам;
  при равенстве очки взявших сгорают.
- Втроём взявший должен набрать больше каждого соперника (настраивается: «больше половины»).
  Иначе он получает только белу, а его остальные очки делятся поровну между соперниками.
- Игра до 301 / 501 / 1001 очка (выбирает создатель стола).

Правила белота сильно различаются по регионам. Если вы играете иначе, логику легко поменять:
она собрана в `core/src/main/kotlin/belot/core/BelotGame.kt`.

## Для разработчика

- `core/` — игровая логика, боты и сетевой протокол (чистый Kotlin, без Android). Тесты:
  `./gradlew -PcoreOnly :core:test` (Android SDK не нужен).
- `app/` — Android‑приложение (без AndroidX, весь интерфейс рисуется кодом).
- Сборка APK: `./gradlew :app:assembleRelease` (нужен Android SDK) или GitHub Actions
  (`.github/workflows/belot-android.yml`).
- Сеть: создатель стола запускает TCP‑сервер (порт 47321) и рассылает UDP‑маяк (порт 47322)
  для автопоиска. Все решения принимает сервер; каждому телефону приходят только его карты.
- Ключ подписи `app/belot-shared.jks` лежит в репозитории специально, чтобы любая сборка
  ставилась поверх предыдущей. Для публикации в магазине его нужно заменить на свой секретный ключ.
